# Studio Dentistico Colombo — sito web

Sito statico (HTML, CSS e JavaScript puri) dello Studio Dentistico Colombo, Patti (ME).

- `sito/` — il sito: è il contenuto da caricare sul hosting (Aruba).
- `strumenti/imposta-sito.py` — imposta dominio, civico e social in tutte le pagine.
- `sorgenti/` — i programmi che generano le pagine (facoltativo).
- `LEGGIMI.md` — guida completa: cosa completare, pubblicazione, Google, recensioni.

Anteprima su GitHub Pages: https://robbcolo.github.io/colombo-dental-web/ (aggiornata da sola a ogni modifica di `sito/`).

La versione precedente (React/Vite) si trova nel ramo `archivio-sito-react`.
